# Анализ продаж компьютерных игр

## О проекте

Учебный проект по исследовательскому анализу данных (EDA) в рамках курса от Яндекс.Практикума.

**Задача:** на основе исторических данных о продажах игр до 2016 года выявить закономерности, определяющие успешность игры, чтобы спланировать рекламную кампанию на 2017 год.

**Контекст:** данные до 2016 года, имитируем декабрь 2016 г. и планируем кампанию на 2017-й. В наборе данных присутствует рейтинг ESRB (Entertainment Software Rating Board) — возрастная категория игры.

## Ключевые выводы

- **Жизненный цикл платформы** — в среднем около 10 лет. Для прогноза на 2017 год актуальны данные не ранее 2007 года.
- **Перспективные платформы на 2017 год:** PS4, XOne и WiiU — они находятся в начале жизненного цикла, продажи стабильны или растут. Платформы PS3, PSP, Wii, X360 подходят к концу цикла.
- **Оценки критиков влияют на продажи** сильнее, чем оценки пользователей. На Wii корреляция Пирсона между продажами и оценкой критиков ≈ 0.24 (p < 0.001), по оценкам игроков ≈ 0.14. На перспективных платформах (PS4, XOne, WiiU) корреляция с критиками ≈ 0.39, с пользователями — статистически незначима.
- **Самые прибыльные жанры:** Shooter, Sports и Action — высокие и средние, и суммарные продажи. Жанры Adventure, Strategy и Puzzle показывают низкие результаты по обоим показателям.
- **Портреты пользователей по регионам:**
  - **Северная Америка:** платформы PS4, XOne, X360; жанры Action, Shooter, Sports; рейтинги «17+», «для всех», «13+».
  - **Европа:** платформы PS4, PC, X360; жанры Action, Shooter, Sports; рейтинги «17+», «для всех», «13+».
  - **Япония:** платформы 3DS, PS3, PSP, WiiU; жанры Role-Playing и Action; игры без рейтинга ESRB популярнее рейтинговых.
  - **Другие регионы:** платформы PS4, PS3, X360; жанры Action, Shooter, Sports.

## Проверка гипотез

1. **Средние пользовательские рейтинги Xbox One и PC одинаковые.**
   - H0: средние рейтинги равны; H1: различаются.
   - Проверка нормальности (Shapiro-Wilk) показала, что распределения не нормальные (p < 0.05), однако равенство дисперсий подтверждено (Levene, p = 0.12), поэтому применялся t-тест.
   - Результат: p-value ≈ 0.041 < 0.05 → **H0 отвергается**, средние рейтинги различаются.

2. **Средние пользовательские рейтинги жанров Action и Sports разные.**
   - Гипотеза проверена, результат интерпретирован в ноутбуке.

## Стек

Pandas, NumPy, Matplotlib, Seaborn, SciPy, Pingouin

## Этапы работы

1. Загрузка и первичный осмотр данных.
2. Предобработка: приведение типов (`year_of_release` → Int64, `user_score` → float, замена `tbd` на NaN), обработка пропусков, расчёт суммарных продаж `total_sales`.
3. Исследовательский анализ:
   - количество выпущенных игр по годам;
   - продажи по платформам и их жизненный цикл;
   - boxplot продаж по платформам;
   - влияние оценок критиков и пользователей на продажи (корреляции);
   - распределение игр по жанрам (средние и суммарные продажи).
4. Портрет пользователя по регионам (NA, EU, JP, Other): топ платформ, топ жанров, влияние рейтинга ESRB.
5. Проверка статистических гипотез.
