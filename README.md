# Анализ рынка компьютерных игр для интернет-магазина

Учебный анализ данных для интернет-магазина «Стримчик», продающего компьютерные игры по всему миру. На основе исторических данных о продажах, оценках, жанрах и платформах нужно выявить закономерности успешности игр для планирования рекламных кампаний. Данные доступны до 2016 года, а кампанию нужно спланировать на 2017-й — это отрабатывает принцип работы с данными, применимый и к более поздним периодам. Также исследуется влияние возрастного рейтинга **ESRB** на продажи.

Этот проект представляет собой учебный анализ данных, в рамках курса Яндекс.Практикум. 

## Задачи проекта

1. **Проанализировать** исторические данные о продажах игр до 2016 года.
2. **Выявить** закономерности, влияющие на коммерческий успех игры.
3. **Составить** портреты пользователей для каждого региона (Северная Америка, Европа, Япония, другие).
4. **Проверить** статистические гипотезы о пользовательских рейтингах.
5. **Сформулировать** рекомендации для планирования рекламной кампании на 2017 год.

## Данные

Проект основан на наборе данных, содержащем информацию об играх, выпущенных до 2016 года. Данные, используемые в проекте, хранятся на Яндекс Диске и включают в себя:

| Поле | Описание |
|---|---|
| `Name` | название игры |
| `Platform` | платформа (например, Xbox, PlayStation) |
| `Year_of_Release` | год выпуска |
| `Genre` | жанр игры |
| `NA_sales` | продажи в Северной Америке (млн копий) |
| `EU_sales` | продажи в Европе (млн копий) |
| `JP_sales` | продажи в Японии (млн копий) |
| `Other_sales` | продажи в других странах (млн копий) |
| `Critic_Score` | оценка критиков (макс. 100) |
| `User_Score` | оценка пользователей (макс. 10) |
| `Rating` | возрастной рейтинг ESRB |

## Ключевые выводы и результаты

- **Жизненный цикл платформ:** В среднем платформы живут около 10 лет. На 2017 год перспективными являются **PS4** и **Xbox One**, в то время как PS3, Wii и X360 находятся на завершающей стадии. PC — стабильная платформа с особым циклом.

- **Факторы успеха:** **Оценки критиков** являются более надёжным индикатором коммерческого успеха, чем оценки пользователей. Корреляция продаж с оценками критиков значительно сильнее.

- **Прибыльные жанры:** Самые прибыльные жанры — **Shooter** (в расчете на игру), **Sports** и **Action** (по общим продажам). Жанры Adventure, Strategy и Puzzle показывают низкие результаты.

- **Региональные различия:**
  - Рынки Северной Америки, Европы и других регионов схожи: популярны экшены, шутеры и спортивные игры. В Европе также сильны позиции PC.
  - **Япония** — уникальный рынок, где доминируют ролевые игры (Role-Playing) и портативные платформы (PSP, 3DS). Рейтинг ESRB здесь не играет значимой роли.

- **Статистические гипотезы:**
  - Разница в пользовательских рейтингах между Xbox One и PC статистически значима, но **мала с практической точки зрения** (размер эффекта `d=0.17`).
  - Пользовательские рейтинги игр в жанре Action **значимо и ощутимо выше**, чем в жанре Sports (размер эффекта `d=0.44`).

## Рекомендации для кампании на 2017 год

1. **Фокус на платформы:** Сделать ставку на **PS4** и **Xbox One**. Для японского рынка учесть **WiiU** и **3DS**.

2. **Приоритетные жанры:** Ориентироваться на **Shooter** и **Action**. В Японии — на **Role-Playing**.

3. **Критерии отбора игр:** При выборе игр для продвижения в первую очередь опираться на **высокие оценки критиков**.

4. **Региональная стратегия:** Рекламные кампании для NA, EU и Other можно унифицировать. Для **Японии** требуется отдельная стратегия, учитывающая её уникальные предпочтения.
