# Анализ рынка компьютерных игр для интернет-магазина «Стримчик»

## О проекте

Этот проект представляет собой учебный анализ данных, выполненный для интернет-магазина «Стримчик», который продает компьютерные игры по всему миру. Цель — выявить закономерности, определяющие успешность игры, чтобы помочь магазину сделать ставку на потенциально популярный продукт и эффективно спланировать рекламные кампании на 2017 год.

**Задача:** На основе исторических данных о продажах, оценках критиков и пользователей, жанрах и платформах определить ключевые факторы успеха игры.

## Цели и задачи

- **Проанализировать** исторические данные о продажах игр до 2016 года.
- **Выявить** закономерности, влияющие на коммерческий успех игры.
- **Составить** портреты пользователей для каждого региона (Северная Америка, Европа, Япония, другие).
- **Проверить** статистические гипотезы о пользовательских рейтингах.
- **Сформулировать** рекомендации для планирования рекламной кампании на 2017 год.

## Технологии и инструменты

- **Язык:** Python 3
- **Библиотеки:**
  - `pandas` — для загрузки, очистки и анализа данных.
  - `matplotlib` и `seaborn` — для визуализации данных.
  - `pingouin` и `scipy.stats` — для проведения статистических тестов.
- **Среда разработки:** Jupyter Notebook

## Данные

Проект основан на наборе данных, содержащем информацию об играх, выпущенных до 2016 года. Данные включают:

| Поле | Описание |
|---|---|
| `Name` | название игры |
| `Platform` | платформа (например, Xbox, PlayStation) |
| `Year_of_Release` | год выпуска |
| `Genre` | жанр игры |
| `NA_sales` | продажи в Северной Америке (млн копий) |
| `EU_sales` | продажи в Европе (млн копий) |
| `JP_sales` | продажи в Японии (млн копий) |
| `Other_sales` | продажи в других странах (млн копий) |
| `Critic_Score` | оценка критиков (макс. 100) |
| `User_Score` | оценка пользователей (макс. 10) |
| `Rating` | возрастной рейтинг ESRB |

## Этапы работы

Проект выполнен в несколько последовательных этапов:

1. **Загрузка и предобработка данных:**
   - Приведение типов данных (например, `Year_of_Release` к `Int64`, `User_Score` к `float`).
   - Обработка пропущенных значений (заполнение года из названия игры, удаление неинформативных строк, замена `'tbd'` на `NaN`).
   - Создание нового признака `total_sales` (общие продажи по всем регионам).

2. **Исследовательский анализ данных (EDA):**
   - Анализ количества выпущенных игр по годам.
   - Анализ продаж по платформам и их жизненного цикла (в среднем около 10 лет).
   - Анализ влияния оценок критиков и пользователей на продажи.
   - Анализ распределения продаж по жанрам.

3. **Составление портрета пользователя по регионам:**
   - Определение топ-5 платформ и жанров для каждого региона.
   - Оценка влияния рейтинга ESRB на продажи в разных частях мира.

4. **Проверка статистических гипотез:**
   - Сравнение средних пользовательских рейтингов для платформ Xbox One и PC.
   - Сравнение средних пользовательских рейтингов для жанров Action и Sports.

5. **Формулировка выводов и рекомендаций.**

## Ключевые выводы и результаты

- **Жизненный цикл платформ:** В среднем платформы живут около 10 лет. На 2017 год перспективными являются **PS4** и **Xbox One**, в то время как PS3, Wii и X360 находятся на завершающей стадии. PC — стабильная платформа с особым циклом.

- **Факторы успеха:** **Оценки критиков** являются более надёжным индикатором коммерческого успеха, чем оценки пользователей. Корреляция продаж с оценками критиков значительно сильнее.

- **Прибыльные жанры:** Самые прибыльные жанры — **Shooter** (в расчете на игру), **Sports** и **Action** (по общим продажам). Жанры Adventure, Strategy и Puzzle показывают низкие результаты.

- **Региональные различия:**
  - Рынки Северной Америки, Европы и других регионов схожи: популярны экшены, шутеры и спортивные игры. В Европе также сильны позиции PC.
  - **Япония** — уникальный рынок, где доминируют ролевые игры (Role-Playing) и портативные платформы (PSP, 3DS). Рейтинг ESRB здесь не играет значимой роли.

- **Статистические гипотезы:**
  - Разница в пользовательских рейтингах между Xbox One и PC статистически значима, но **мала с практической точки зрения** (размер эффекта `d=0.17`).
  - Пользовательские рейтинги игр в жанре Action **значимо и ощутимо выше**, чем в жанре Sports (размер эффекта `d=0.44`).

## Рекомендации для кампании на 2017 год

1. **Фокус на платформы:** Сделать ставку на **PS4** и **Xbox One**. Для японского рынка учесть **WiiU** и **3DS**.

2. **Приоритетные жанры:** Ориентироваться на **Shooter** и **Action**. В Японии — на **Role-Playing**.

3. **Критерии отбора игр:** При выборе игр для продвижения в первую очередь опираться на **высокие оценки критиков**.

4. **Региональная стратегия:** Рекламные кампании для NA, EU и Other можно унифицировать. Для **Японии** требуется отдельная стратегия, учитывающая её уникальные предпочтения.
